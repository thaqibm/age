Inside the demo

The games use AGE’s C++ entity IDs and packed component arrays. Movement, collision, scoring, and particles run in WebAssembly.

A new browser renderer draws the scene in one instanced WebGL call. The original terminal games remain in the repository.

Push the engine

Start with 2,000 drones and keep adding more. Invulnerable ship; no time limit. Up to 5,000 entities.

Timings are measured on your device. Draw time measures CPU submission, not GPU completion.
